# Portfolio notes

This repository can be presented as an experimental AI/API project rather than as a production anti-cheat product.

The strongest engineering signals are:

- FastAPI API construction;
- multipart file handling;
- environment-based configuration;
- integration with an external AI API;
- multimodal request construction;
- separation of application bootstrap and routing;
- Python dependency management with Poetry.

For a stronger portfolio signal, prioritize modernization, tests, Docker, CI, and an evaluation methodology before adding additional product features.
