# Interview talking points

When presenting this repository, focus on what you built and what you learned from the proof of concept.

Useful topics:

- Why FastAPI was suitable for a small HTTP inference API.
- How multipart uploads and temporary files are handled.
- How external API failures should be isolated from route logic.
- Why model output must be evaluated rather than treated as ground truth.
- How you would migrate a deprecated provider/model integration.
- How Docker, tests, CI, authentication, rate limiting, and observability would move the project toward production readiness.

Be explicit about the project's experimental status and about which portions of the implementation are your own work.
